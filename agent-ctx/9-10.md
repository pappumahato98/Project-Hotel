## Key Design Decisions
- Used plain functions instead of `useCallback` because the project uses React Compiler which handles memoization automatically and errors on manual `useCallback` with complex dependencies
- Floating action bar is positioned with `mt-2` (in content flow, not fixed to viewport) as specified
- CSV export uses Blob/URL.createObjectURL pattern for client-side download
- "Settle Selected" opens existing dialog for first selected item (reuses existing payment flow)
- "Checkout Selected" in Departures uses existing `batchCheckoutMutation`
- Refresh uses `queryClient.invalidateQueries()` with appropriate query keys
- Compact view applies `py-1.5` to reduce row height on checkbox and first data cell
